One emoji, one smile: 🤗 — a warm hug for a stranger. No words, no caption,
no explanation, just open arms. A hug reads as kind and friendly at first
glance, needs no context, and works the same for a stranger of any age or
background. It is a chosen gesture, not the first smiley that comes to mind,
and it carries no irony, sarcasm or flirtation. The program writes exactly
that one emoji to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
